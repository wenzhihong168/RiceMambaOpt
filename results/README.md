# Published result tables

Machine-readable transcriptions of the principal quantitative results:

- `forward_model_benchmark.csv` — mean cross-validated R² for the main neural baselines and RiceMambaOpt.
- `inverse_recovery.csv` — holdout recovery of milling time and speed.
- `cultivar_optimization.csv` — Table 2, cultivar-specific inverse optimization.
- `constraint_ablation.csv` — Table 3, feasible versus unconstrained solutions.

Values are reported as published in [Foods 15(16), 2812](https://doi.org/10.3390/foods15162812).
